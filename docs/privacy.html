Privacy Policy — Worldglass

Last updated 17 August 2026

Worldglass does not collect, transmit, or store any personal data. There is no account, no analytics, no tracking, and no server that belongs to this project. Everything happens inside your own browser.

What the extension does with the text you select

When you highlight text, Worldglass looks it up in dictionary files that are bundled inside the extension itself and stored on your computer. The text you select is never sent anywhere. Dictionary lookup, word breakdown, and reading aids all run locally.

What is stored, and where

Worldglass saves a small amount of data using Chrome's local extension storage on your own device:

  • Your settings (Chinese reading style, script preference, text size, whether the floating OCR button is shown).
  • Words you explicitly save with the star button, and their review progress.
  • Per-site language choices, when you tell Worldglass which language a site is in.

This data stays on your device. It is not synced to any server by this extension, and it is removed if you uninstall the extension. You can delete saved words at any time from the toolbar popup.

Reading text inside images (OCR)

The OCR feature recognises text using an engine bundled with the extension. Images and recognised text are processed in memory on your device and are not uploaded, stored, or shared.

Translating a whole sentence

The "Translate this sentence" feature uses Chrome's own built-in on-device translator, which runs locally on your machine. Worldglass does not operate a translation service.

If that translator is unavailable and you choose to click the Google Translate link shown as a fallback, that opens Google Translate in a new tab and is governed by Google's privacy policy. Nothing is sent unless you click that link yourself.

Dictionary downloads

Some builds fetch additional dictionary data files from this project's public GitHub repository the first time you use a given language. These are plain data files, no code is downloaded or executed, and the request contains nothing about you beyond the ordinary network request GitHub receives for any public file.

Why the extension asks for access to websites

Worldglass requests access to web pages so that it can read the text you have highlighted on the page you are looking at, and draw its popup there. It uses that access only in response to your selection or your click. It does not read pages in the background, build a browsing history, or send page contents anywhere.

Children

Worldglass is suitable for learners of any age. Because it collects no data at all, it collects no data from children either.

Changes

If this policy ever changes, the revised version will be published at this address with a new date. Any change that affected data handling would be described plainly here.
